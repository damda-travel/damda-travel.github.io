# 전북 관광 정보 지도

전북특별자치도 14개 시·군의 관광지 33곳을 일러스트 지도에서 탐색하고, 장소 저장과 여행 일정 만들기까지 이용할 수 있는 반응형 웹앱입니다.

## 주요 기능

- 전북 14개 시·군 지도 핀 및 빠른 지역 선택
- 관광지명·지역·주소·태그 통합 검색
- 맛집·카페, 역사·문화, 자연·힐링, 축제·행사 필터
- 추천순·이름순·지역순 정렬
- 관광지 상세 정보, 카카오맵 검색 연결, 공유
- 기기 내 장소 저장 및 여행 보관함
- 기간·테마·중심 지역 기반 여행 일정 초안 생성
- 추천 코스 3종과 일정 저장·복원
- 모바일 상단 카테고리 메뉴 및 하단 주요 메뉴
- 한국관광공사 TourAPI 4.0 선택 연동

## 실행

정적 웹서버로 프로젝트 폴더를 연 뒤 브라우저에서 접속합니다.

```bash
npx http-server . -p 8085 -a 127.0.0.1 -c-1
```

접속 주소: `http://127.0.0.1:8085`

## 데이터 주의사항

- 기본 관광지 정보는 `js/tourData.js`에서 관리합니다.
- 운영시간, 휴무일, 입장료는 변동될 수 있으므로 방문 전 공식 관광정보를 확인해야 합니다.
- 기본 이미지 중 일부는 관광 분위기를 보여주는 외부 이미지입니다. 실제 서비스 공개 전 사용 권한과 장소 일치 여부를 최종 검수해야 합니다.
- TourAPI 키를 브라우저에 직접 저장하는 기능은 개발·테스트용입니다. 공개 서비스에서는 서버를 통한 안전한 연동이 필요합니다.
